## 文書の読み方

**確定要件**は会話で合意した製品上の方針を指す。**実装案**は要件を満たすための提案であり、言語・ライブラリ・数値・API名まで採用済みという意味ではない。**未決定**は実装前に決める事項を指す。

設計書の主な例は衣服・商品画像・記事・数表である。検索／後処理の選別設定と、アプリ自体の権限・停止・ファイル保護などの実行基盤は分けて扱う。

標準搭載の接続部や選別フィルターも公開された共通APIを使用する。検索成功を保証するのではなく、何を指定し、何が実行され、何が取得できなかったかを確認し、設定を変えて試し直せることを本体の責務とする。
