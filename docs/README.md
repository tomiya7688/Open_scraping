# Open_scraping 設計ドキュメント

**コアの役割は、ユーザーが指定した条件で検索し、画像・テキスト・動画・統計／数表のデータを取得すること。フィルターはコアに追加する任意の機能であり、取得の成立条件ではない。**

コンセプト：**Lang to Data by Web**。ローカル中心のOSSとして、ユーザーが検索先・ブラウザ・検索条件・取得間隔を選択する。

- 作成・改訂日：2026-09-22（Asia/Tokyo）
- 状態：設計。API、設定、画面、プラグインは実装済みという意味ではない。
- 予定：0.xは基盤、1.0.0でテキスト・画像・統計／数表の取得、1.1.0で動画の取得。

## コアと追加機能

```text
コア：検索要求 → 検索 → 取得 → データ・取得元の記録 → 取得結果

追加機能：必要な場合に、検索語の解釈・展開、検索フィルター、
          取得済みデータの解析・選別・加工を接続する。
```

取得結果は解析・選別を通さなくても保存・閲覧・出力できる。フィルターを一つも導入していない構成を正式にサポートする。内製フィルターの標準同梱と、コアの必須依存は別である。

停止、再読み込み、ブラウザ開き直し、取得間隔、出典・失敗の記録は、検索・取得を動かすための基盤として維持する。フィルターの導入有無には依存しない。

## 今回の改訂

コアと追加機能を同列の必須処理に見せていた記述を修正した。コアの設定・完了判定・保存・出力には選別結果を要求しない。モデルやフィルターが存在しないことは、コアの不備ではない。

追加機能を使用していない状態を、機能の「解除」として扱わない。標準部品も外部部品も公開APIを使い、必要なものを導入・使用する構成とする。
