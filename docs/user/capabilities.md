# 現在の機能と制限

[利用者向けトップ](README.md) · [開発状況と構成](../../README.md)

この表は **2026年10月時点の main ブランチ** を基準にした案内です。最新の実装・リリース判断はリポジトリと Issue / PR を確認してください。PRが存在するだけでは main に搭載されたとは限りません。

| 機能 | 現状 | 備考 |
| --- | --- | --- |
| FlowConfig / component manifest の検証 | 基盤実装済み | JSON Schema と意味検証 |
| モック実行・worker通信 | 基盤実装済み | 検証用。実サイトへの通信ではない |
| ブラウザ・検索サイト連携 | 未実装 | Chromium / Firefox / Google / Bing / DuckDuckGo などは計画段階 |
| ダウンロード・出典付き保存・直接出力 | 未実装 | 個別部品として実装予定 |
| テキスト・画像・数表・動画抽出 | 未実装 | 契約とロードマップは策定中 |
| 商品検索・比較・おすすめ | 未実装 | 任意サイトを選択できる標準フローを構想（#41） |
| 使える GUI / CLI / HTTP API | 未実装 | ソース上の枠・スタブのみ |
| グローバル非常停止（Esc/マウス） | **OS実装未完成** | 必須の設計要件。実装まで安全性を保証しない |

## 設計上の注意

- すべてのサイト・認証方式・データ形式に対する取得成功を保証するものではありません。対応は部品・ブラウザ・接続条件によって異なります。
- 検索・取得条件や必要な接続先は利用者が指定する設計です。未選択のサイトを自動で追加したり、失敗を成功として扱ったりしません。
- 取得した情報の利用条件、個人情報、権利関係、アクセス先の規約等は、利用者・配布者が用途に応じて確認する必要があります。
- 設計上の必須機能と **実装済み** は別です。実ブラウザやOS入力に関係する機能は対応Issueの検証が完了するまで未実装として扱います。

将来の構成・受入条件は [開発ロードマップ](../developer/roadmap.md) と [Issue 一覧](https://github.com/tomiya7688/Open_scraping/issues/1) にあります。
