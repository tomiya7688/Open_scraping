# 用語集

[利用者向けトップ](README.md)

| 用語 | 意味 |
| --- | --- |
| **Flow / FlowConfig** | 部品の接続、入力、実行条件、出力先を記述する設定 |
| **Component** | 検索・取得・加工・保存などを担当する交換可能な処理部品 |
| **Contract** | 部品が提供する操作、入出力、能力、バージョンなどの約束 |
| **Manifest** | 部品の実装版、権限、必要な契約、起動方式などの宣言 |
| **Core** | 部品の内容を知らずに順序・並列・停止・参照配送を扱う共通基盤 |
| **Host** | 部品の登録・起動・通信・権限・終了を引き受ける実行環境 |
| **Run / Operation** | 一回のフロー実行 / 一つの部品操作 |
| **DataRef** | 大きなデータ本体を直接コアに流さず、保存先や寿命を示す参照 |
| **Binding** | Flow内の部品名と、実際の部品実装・版・依存先の対応 |
| **Snapshot** | 実行時点の設定・版・状態などを後から追えるように固定した記録 |
| **標準フロー** | 出荷時に提示する構成例。コアに専用処理があるという意味ではありません |

データ構造の正確な定義は [開発者向け正式契約](../developer/contracts.md) にあります。
