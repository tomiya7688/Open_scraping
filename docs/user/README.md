# 利用者向けガイド

Open_scraping を**使う人・試したい人**のための入口です。コードの詳細や共同開発手順は [開発者向けガイド](../developer/README.md) を参照してください。

> **現在の main は 0.x の開発途中です。** 完成した GUI・CLI・一般向けスクレイピング機能の配布はまだありません。「予定」と書かれた機能は操作できる機能ではありません。

## プロジェクトの考え方

処理の手順を **Flow**、個々の処理を交換できる **Component** としてつなぐ仕組みです。ブラウザ・検索・ダウンロード・選別・保存はコアの固定機能ではなく、追加・交換する部品として計画しています。実装や契約の対応範囲は各部品に依存します。

グローバル Esc／物理マウス入力による非常停止は必須設計ですが、**現行 main では OS レベルの実装はありません**。未完成の自動化を安全機能が実装済みであるかのように案内しません。
